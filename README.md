# Nursery Shopping Application

[![Type: Mobile / E-Commerce](https://img.shields.io/badge/Type-E--Commerce-green.svg)]()

> An e-commerce mobile/web platform for plant lovers and nurseries, enabling users to explore indoor/outdoor plants, view care guides, and manage shopping carts.

---

## ✨ Features

- **Plant Catalog**: Filter by indoor, outdoor, sunlight needs, and watering schedules.
- **Shopping Cart & Checkout**: Interactive cart management and order summary.
- **Care Instructions**: Detailed plant maintenance guidelines for buyers.
